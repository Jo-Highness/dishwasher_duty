# Security Policy

## Supported versions

Only the latest released version of Dishwasher Duty receives security fixes.
Please update to the newest release before reporting an issue.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| older   | :x:                |

## Reporting a vulnerability

Please report security issues **privately** using
[GitHub Security Advisories](https://github.com/Jo-Highness/dishwasher_duty/security/advisories/new).

Do not open a public issue for security-sensitive reports.

We will acknowledge your report as soon as possible and keep you updated on
the fix and disclosure timeline.

## Data handling

Dishwasher Duty is a local-only Home Assistant integration:

- All data (claims, credits, statistics) is stored **locally** within your
  Home Assistant instance's storage.
- It does **not** connect to any cloud service.
- It does **not** collect, store, or transmit any credentials or personal
  data outside of your Home Assistant installation.
